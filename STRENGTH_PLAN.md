**3a + 3b are a superset:** calf left → calf right → Pallof → rest 60 s. Never rest between 3a and 3b.

**Narrow stance is a different lift from Tuesday's squat** — hip-width or narrower, toes near-forward, same heel elevation. Log it under its own name in Strong.

## Progression

**Hit the top of the rep range on every working set → add load next session and drop back to the bottom of the range.**

Reps are the gate; RPE is the ceiling. If you hit the top but it felt like a 10, hold the load instead.

RPE = reps in reserve. **8** = two left · **9** = one · **10** = none. Only calf raises should reach 10.

Same load, same reps, two sessions running → drop that lift 10% and build back.

Lead Bulgarian split squats with a different leg each week. Judge left/right asymmetry only from the first set of each leg.

## Stop rules

- **No safety bars.** Never grind a squat rep — if it slows, rack it.
- **Left knee (BSS).** Any knee pain that outlasts the session stops loaded unilateral work until it clears.
- **Lower back (RDL).** Stop the set when the hinge position softens, not when the hamstrings give out.
- **Protein 110–135 g/day.** The one that is not optional.
